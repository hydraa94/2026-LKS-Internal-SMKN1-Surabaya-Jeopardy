## Description
Tim SOC SMKN1SBY mendeteksi lonjakan traffic HTTP yang tidak wajar menuju web server internal pada rentang waktu tertentu. Sensor IDS memicu alert terkait pola request yang mengandung karakter SQL yang menyasar endpoint

Sebagai bagian dari prosedur incident response, tim jaringan berhasil menangkap seluruh traffic masuk dan keluar server selama periode serangan dan menyimpannya dalam file capture.pcapng.

Kamu ditugaskan sebagai bagian dari tim DFIR untuk merekonstruksi jalannya serangan: teknik SQL Injection yang digunakan, data apa yang berhasil dicuri, dan bukti apa saja yang bisa dijadikan indikator kompromi (IOC).
